# scripts/seeds — 사람이 확정한 목록

기계가 만들 수 없고 **사람의 판단이 들어간** 자료를 여기 둔다. 코드가 아니라 자료지만
git 에 넣는 이유는, 이 판단이 없으면 다음 사람이 처음부터 다시 지도를 봐야 하기 때문이다.

## district_rone_map.csv — 상권 ↔ 부동산원 임대통계 이름 잇기

| 칸 | 뜻 |
|---|---|
| `district_id` | `district.district_id` (서울은 숫자, 대전은 `sbiz-` 접두) |
| `rone_region_nm` | `rent_stat.region_nm` **전체 경로** (`대전>둔산`, `서울>강남>테헤란로`) |
| `match_method` | `exact` / `normalized` / `token` / `manual` |
| `note` | `manual` 이면 **왜 그렇게 판단했는지**. 근거 없는 manual 은 검증할 수 없다 |

한 상권이 **행 둘**을 가질 수 있다 (PK 가 `(district_id, rone_region_nm)` 복합인 이유).
아래 "이중 경로" 절 참조.

- 만드는 법: `python scripts/build_rone_map.py --candidates-out cand.csv` 로 후보를 뽑고,
  사람이 골라 이 파일로 확정한다.
- 넣는 법: `python scripts/load_rone_map.py --dry-run` → 이상 없으면 `--dry-run` 없이.
- **여기 없는 상권은 "아직 이을 근거가 없다"는 뜻이고 그 상태가 정상이다.** 없는 매핑을
  지어내면 임대료 추정이 배 단위로 틀어진다 — 빈칸이 틀린 값보다 낫다.

### match_method 를 얼마나 믿을 수 있나

- `exact`·`normalized` — 이름이 같다. 가장 강한 근거.
- `token` — **앞말만 겹친다**(`수유` ⊂ `수유북부시장`). "같은 이름 계열"이라는 뜻이지
  "같은 상권"의 보증이 아니다. 좁은 추정에 쓸 때는 이 등급을 빼고 쓰는 것을 권한다.
- `manual` — 사람이 지리로 정했다. `note` 에 근거가 있다.

### 이중 경로 — 한 상권이 R-ONE 경로를 **둘** 갖는다 (실측 확정 2026-08-14)

처음엔 "한 이름이 권역 둘에 있다"를 **가설**로 남겼는데, 라이브 `rent_stat` 을 떠서
**사실로 확인**했다. 부동산원이 통계 종류마다 서울 권역을 다르게 나눈다:

| bld_type | 경로 |
|---|---|
| 오피스 | `서울>여의도마포>{공덕역·당산역·여의도}` · `서울>기타>홍대/합정` |
| 소규모·중대형·집합상가 | `서울>영등포신촌>{공덕역·당산역·여의도·홍대/합정}` |

그래서 이 넷은 **두 경로를 모두** 넣는다(해당 상권 **20곳 × 2 = 40행**, `note` 에
"이중 권역(오피스/상가 분할 상이)"). 하나만 넣으면 그 상권의 오피스(또는 상가) 통계가
조용히 사라진다. (이름으로 걸린 상권은 21곳이지만 `연남동(홍대)` 한 곳은 아래 "자동과
다르게 고른 것"대로 `동교/연남` 으로 옮겨 이중 경로에서 빠졌다.)

⚠️ 이 규칙은 앞말 겹침 점수 관문을 **건너뛴다**. 그래서 점수 0.30 미만인데 `token` 으로
적힌 행이 10개 있고, 그 행들은 `note` 에 "…이중 권역 규칙으로 승격"을 달고 있다 —
`match_method` 만 보고 신뢰도를 오판하지 않게 하기 위해서다.

`bld_type` 칸은 **일부러 두지 않았다** — 조회가 `(이름 경로, bld_type)` 으로 rent_stat 을
찾을 때 존재하는 쪽이 자연히 골라지므로, 자료가 이미 아는 것을 두 번 적을 이유가 없다.
전제("종류가 다르면 경로도 다르다")가 깨지는 순간은 `load_rone_map.py` 의 **관문 ③** 이
잡는다 — 한 상권이 같은 종류·같은 분기에서 경로 둘에 닿으면 적재가 통째로 멈춘다
(임대료가 두 번 잡히는 것은 에러가 아니라 **숫자가 조용히 틀리는** 사고다).

### 2026-08-14 첫 판에서 사람이 내린 판단 (같은 고민을 되풀이하지 않으려고 남긴다)

**자동 후보에서 뺀 것 — 이름 앞말은 같은데 딴 동네다**

| 상권 | 자동이 이으려던 곳 | 뺀 이유 |
|---|---|---|
| 용산구청 | 서울>기타>용산역 | 녹사평(이태원 쪽)이라 용산역 상권이 아니다 |
| 영등포구청역(+2·6번) | 서울>영등포신촌>영등포역 | 영등포구청역과 영등포역은 1.5km 떨어진 다른 역 |
| 당산2동(영등포우체국) | 서울>영등포신촌>영등포역 | 당산동인데 별칭 때문에 영등포로 걸렸다 |
| 뚝섬유원지역 1번 | 서울>기타>뚝섬 | 광진구 자양동. 뚝섬 상권(성동구 성수동)과 다른 곳 |
| 홍대부중 | 서울>기타>홍대/합정 | 성북구. 홍익대 사대부중이지 홍대 상권이 아니다 |
| 성신여대운정그린캠퍼스 | 서울>기타>성신여대 | 강북구 미아동의 별개 캠퍼스 |
| 신월7동 골목시장(약수시장…) | 서울>기타>약수역 | 양천구 신월동. 중구 약수와 이름만 같다 |
| 군자초등학교 (3110223) | 서울>기타>군자 | **동대문구 장안동** 소재. 광진구 군자동 상권이 아니다 |

`성신여대운정그린캠퍼스`·`신월7동 골목시장`은 `build_rone_map.py` 의 **②-b 구가 홀로 다른
후보** 점검이 짚어 줬다(`기타` 권역은 서울 전역이라 관문이 없어, 이 점검이 유일한 그물이다).

`군자초등학교`는 **②-b 가 경고했는데 사람이 눈으로 넘기고 확정해** 첫 판에 들어갔고,
적대검증이 주소를 실측해 잡아냈다. `서울>기타>장안동` 잎으로 옮길지도 봤지만 그 잎의 기존
행들이 광진(11215)·중랑(11260)·동대문(11230)으로 흩어져 있어 근거가 서지 않았다 —
**옮기지 않고 미매핑으로 둔다.**

⚠️ **그래서 ②-b 는 이제 경고가 아니라 관문이다.**
`python scripts/build_rone_map.py --seed scripts/seeds/district_rone_map.csv` 를 돌리면,
②-b 가 경고한 행이 확정본에 **근거 없이** 남아 있을 때 **종료코드 2 로 멈춘다**. 통과시키려면
그 행을 빼거나, 경계에 걸친 정당한 예외임을 `note` 에 `구 경계 확인` 이라고 적어야 한다
(지금 통과 중인 4건: 신사역=강남/서초, 구로디지털단지역 4번=구로/영등포, 목동사거리=양천/강서,
사당역 4번=동작/관악). 확정본을 고칠 때마다 이 명령을 한 번 돌리는 것이 이 표의 마지막 관문이다.

⚠️ **②-b 의 사각지대**: 붙은 상권이 **하나뿐인** R-ONE 상권은 비교할 다수가 없어 못 짚는다.
`홍대부중`이 정확히 그랬다(첫 판에서 홍대/합정에 붙은 유일한 상권이었다) — 사람이 "붙은 상권이
1개인 R-ONE 목록"을 따로 훑다가 찾았다. 다음 판에도 그 목록은 눈으로 한 번 보는 것이 좋다.

**확신이 없어 일부러 안 이은 것** — 다음 사람이 다시 고민하지 않게 사유를 남긴다

- `대전>관평동` ← 구즉우체국? **아니다.** 구즉동과 관평동은 유성구 안의 다른 동이다.
- `대전>대전동구청` ← 대응할 상권이 없다(동구 상권 3개는 대전역·가오동·고속터미널).
- `서울>강남>양재말죽거리` ← 말죽거리(양재역 남측)에 해당하는 상권 이름이 없다.
- `유성고속터미널` ← `대전>복합터미널` 은 동구 용전동의 대전복합터미널이다. 유성은 다른 곳.
- 더케이호텔·노원 을지대학교병원·구로역 계열 ← 앞말만 같고 상권이 다르다
  (구로역과 구로디지털단지역은 서로 다른 역이다).

**자동과 다르게 고른 것**

- `연남동(홍대)` → `서울>영등포신촌>동교/연남`. 자동은 원본이 이름에 달아 둔 별칭
  `(홍대)` 때문에 `홍대/합정` 으로 갔지만, R-ONE 에 더 좁은 잎 `동교/연남` 이 따로 있고
  이웃 상권(연트럴파크·동교초등학교)도 그쪽이다. 더 좁은 잎이 있으면 그쪽이 낫다.
