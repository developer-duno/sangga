## 5. 이 문서를 고치는 때
1. 수집기·표·함수를 **새로** 만들었다 → 카드 추가(§0 표 + §1) · 신선도 함수에 줄을 더했으면 "주기·적재"에 규칙을 적는다.
2. 적재해서 행 수·분기가 바뀌었다 → 그 카드의 숫자와 "잰 날짜"(PROGRESS 와 같은 값).
3. 받을 수 있는 자료를 새로 알았거나 조건이 바뀌었다 → §4.
4. 한계가 해소됐다 → 그 줄에 취소선 + 근거(알려진한계와 같은 방식).
5. 열람 페이지(아티팩트)는 이 문서를 고친 뒤 다시 올린다 — 페이지 머리에 "기준 커밋"을 적는다.
