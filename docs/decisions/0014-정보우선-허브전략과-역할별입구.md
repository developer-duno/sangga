# 0014. 정보 제공이 먼저다 — 허브 전략·역할별 입구·매물은 링크로

날짜: 2026-08-19 / 상태: 확정 (사장님 방침) / 결정 0013 이후 전략 재정립

## 0. 이 결정이 다른 모든 것보다 위에 있다

사장님 원문:
> **"철저하게 사용자 입장에서 사용자가 원하는 데이터를 보기 쉽게 해주는 것이 우리만의 장점이 되어야 해."**
> "정보제공에 의미를 둬줘. **수익은 나중에 발생해도 늦지 않아.**"
> "우선은 수익은 생각하지 말아줘. **정보제공 우선순위를 둬. 돈은 나중이야.**"

경쟁사 실측에서 "시장이 돈 받는 지점 = 가져나가기(PDF·엑셀)·정밀 필터"를 확인했으나
**수익 설계는 전면 보류**한다.

### 금지 (설계·구현에서 넣지 않는다)

- ⛔ **유료 벽** — 정보를 감추고 결제를 요구하는 구조
- ⛔ **가입·로그인 유도** — 로그인 없이 전부 보인다
- ⛔ **문의 강요** — 정보를 보려고 연락처를 남기게 하는 구조
- ⛔ 요금제·구독·결제 화면

## 1. 우리는 무엇인가 — 허브

> **"매물 보는 곳"이 아니라 "그 건물이 어떤 건물인지 알려주는 곳"**

경쟁하지 않고 **앞에 선다.** 1분 무료 요약을 주고, 더 필요하면 잘하는 곳으로 넘긴다.

### 왜 파이가 커지나
기존 서비스는 같은 손님을 놓고 경쟁하지만, 우리는 **지금 도구가 없어 못 오던 손님**을 데려온다
(실측: 알스퀘어는 상담 전화가 유일 입구 · 밸류맵은 탭 12개 · 부기사는 첫해 500만원 →
그래서 **2026년에도 엑셀로 매물 관리하는 프로그램이 팔린다**). 넘긴 손님은 경쟁사에게도 이득이다.

### 넘기는 곳 (실측 44곳 근거)
매물 → 네이버·네모 / 깊은 분석 → 밸류맵·디스코 / 매출·유동인구 → 소상공인365 / 지도 → 카카오맵

## 2. 매물은 직접 다루지 않는다 — 링크로

- 일반 매물의 **공식 데이터 통로가 어디에도 없다**(네이버·직방·다방·네모·KB 전부 "광고비 내고 올리세요")
- 크롤링은 **2025-12 특허법원 판결로 막혔다**(네이버 부동산 DB 무단수집 → 배상 8,000만원 + 서버 삭제)
- ⚠️ **개별 매물로 보내는 딥링크는 불가**(실측) — 매물 URL 의 고유번호는 중개사가 등록하는 순간
  네이버가 발급하므로 우리 주소·좌표로는 만들 수 없고, 매물이 내려가면 링크도 죽는다.
  **지도 위치 링크는 가능**(`map.kakao.com/link/map/이름,위도,경도` — 직접 열어 확인).

### 예외: 분양 상가는 직접 수집한다
나라가 공개하는 공공 API 라 법적 위험 0. 확인된 출처 4곳:
LH 청약플러스 단지내상가(data.go.kr/15057999) · 서울시 건축허가대장 분양(OA-15668) ·
청약홈(15098547) · 한국부동산원 REBPP "분양상가"(전국 1㎡당 환산보증금+위경도)

## 3. 역할별 입구 — 찾는 대상이 다르므로 입구를 가른다

| 역할 | 무엇을 찾나 | 시작점 |
|---|---|---|
| 투자자 | **이 건물** 사도 되나 (매매·값·수익) | 건물 검색 |
| **창업자** | **어디가 좋을까** (임대·사람·경쟁 가게) | **지도·상권** |
| 중개사 | 고객이 물어본 그 건물 (둘 다) | 건물 검색 + 뽑기 |

⭐ **창업자는 건물 이름을 모른다.** "강남에서 카페 자리"를 찾는 사람에게 건물명 검색은 답이 아니다.
현재 검색은 투자자·중개사용으로만 만들어져 있었다(사장님 지적).

**자료는 한 벌, 시선만 셋.** 화면 틀은 하나만 만들고 카드 순서와 접힘만 바꾼다.
데이터를 거르거나 숨기지 않는다.

## 4. 공통 흐름과 컨택

```
찾기 → 한 장 요약(그림 위주) → 펼쳐 보기 → 뽑기(인쇄·PDF)
```
가운데 **한 장 요약**과 맨 끝 **뽑기**가 지금 통째로 없다.

**컨택은 열어두되 강요하지 않는다.** 사장님이 공인중개사 자격 보유 → 매물·중개 문의를 받을 수 있다
(공인중개사법 제18조의2 관문 통과). 단 **정보를 충분히 본 뒤 원하면 누르는 자리**로만.
- 투자자 → "이런 물건 찾아주세요" / 창업자 → "이 근처 자리 알아봐 주세요" / 중개사 → "우리 사무소에서 쓸 수 있나요"

⚠️ 허브 전략에는 원래 **"넘기기"만 있고 "받기"가 없었다**(적대검증도 "경쟁사의 무료 전처리 도구가
된다"고 경고). 사장님 지적으로 구조가 닫혔다 — **남을 추천했기 때문에 우리 말이 믿음직해진다.**

## 5. 링크 배치 — 끝에 모아서, 카드 순서와 맞춤

항목 카드마다 배지를 다는 안은 **기각**. 자체 시안에서 "임대 사정" 카드에 소상공인365(실제로는
매출·유동인구 서비스)를 붙이는 오매칭을 냈다. 역할 3개 × 항목 5개로 판단이 갈려 위험이 구조적이고,
인쇄물에서도 카드마다 빼내야 해 실수가 난다. **페이지 끝 한 구역**이면 인쇄 시 그것만 제외하면 된다.

## 6. 반박을 통과한 우리 강점 (44곳 실측 대비)

1. **건물별 임대 지표**(공실률·㎡당 임대료·수익률) — 상가 임대료는 신고 의무가 없어 실거래가
   존재하지 않는다. 우리 원천은 **국세청 확정일자 기반**이라 크롤링으로도 돈으로도 못 구한다. 44곳 중 0곳.
2. **층을 그림으로 쌓아 보여주기** — 국내 사례 0건(디스코·부동산플래닛조차 표와 목록).
3. **"이 지역은 성적이 나빠 안 보여준다"고 먼저 말하기** — 44곳 중 0곳.

### ⛔ 차별점이 아니었던 것 (정직하게)
- "층별 정보를 보여주는 곳이 없다" → **틀림**(부동산플래닛·디스코가 전국에서 이미. 우리는 30개 구뿐)
- "층×업종을 아무도 못 채웠다" → **틀림**(원픽랩은 개업·폐업 시점까지)
- "17년 실거래가 특별하다" → **틀림**(국토부가 2006년부터 전 국민 공개)
- ⚠️ **우리 자료 7종은 전부 공개 데이터라 독점 자산이 0이다.** 방어선은 조립·표현·속도뿐.
