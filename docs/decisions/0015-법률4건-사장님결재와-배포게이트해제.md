## 1. 이 결재가 바꾸는 것

- **배포의 법률 게이트 해제** — 배포는 이제 순수 기술 작업(PostgREST public→api 전환 + 배포 설정)만 남음.
- 상호명이 걸려 있던 항목들의 게이트 해제: **상호명 검색**(색인 기설치) · **인쇄물 상호명**.
- **개업·폐업 diff / 생존기간**은 법률 게이트는 풀렸으나 **기술 선행 결함**(점포 조회가 전역
  최신 분기 · biz_no 불연속 · 분기별 결측률 변동)이 남아 여전히 후순위 — `docs/ROADMAP.md` 참조.
- 유지되는 것: "적정가격·감정가·평가액" 표현 금지(절대 규칙 2)와 근거·표본 병기(절대 규칙 3)는
  결재와 무관하게 계속 지킨다 — 결재 ③의 취지 자체가 "폭 + 근거" 방식이다.

## 2. 상가임대차법 2026-05-12 개정분 조사 결과 (Claude, 2026-08-22)

- 개정 핵심 = **임대인의 관리비 내역 공개 의무화**(청소비·경비비 등 14개 항목 세분 고지 —
  차임 5% 상한을 관리비 인상으로 우회하던 관행 차단). 2025-11-11 공포, 2026-05-12 시행.
- 이는 **임대인에게 지우는 의무**이지 정보 제공 서비스에 새 의무를 지우는 규정이 아니다.
- 화면 문구 전수 대조(grep: 관리비·임대료·임대차·보증금·권리금·월세·갱신): 임대차 관련 문구는
  `PriceBandSection` 의 "사고파는 값이고 월세·보증금이 아닙니다"(사실 안내) 1건뿐 — **충돌 0**.
- 앞으로 지킬 지침 2개:
  1. 임대 통계 카드(ROADMAP Wave 3)를 만들 때 **"임대료 통계에 관리비는 포함되지 않습니다"** 한 줄.
  2. 안내 페이지에서 임대차 계약을 다루게 되면 관리비 14항목 공개 의무를 내용에 반영.
- 근거: 법률신문·김장 법률사무소 뉴스레터(2025-11 개정 공포 보도), 국가법령정보센터 상가건물
  임대차보호법 조문.
