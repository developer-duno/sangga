## 함정 (구현 때 지킬 것 — 맹점 검사관 17건 반영 뒤)

1. **분기 인자 무시**(상주·직장): 0033 의 「분기 한 칸씩 이어받기」가 그대로 안 맞는다 → 분기 없는 URL + 쪽 번호 이어받기 · 받은 뒤 **분기별 파일로 나누는 시험**을 둔다 · 미게시 분기 INFO-200 은 pending 유지(0033 그대로).
2. **연 1회 자료의 중복**: 22분기에 같은 값이 4번 → 신선도는 「값이 바뀐 분기」를 기준으로(~~새 갈래 `seoul_yearly`~~ → **2026-10-31 PR②: `none`(예정일 없음 · 👤 10-31) + 기준 글 합성**「상주 2023년 4분기, 직장 2024년 4분기」 · 게시월은 👤 결정으로 불필요 — 갱신일 2026-09-11 만 기록) — 세 인구 자료를 한 줄로 묶으면 하나만 낡아도 매번 「지났습니다」가 되므로 **줄을 셋으로 나눈다**(추정매출 · 길단위인구 · 상주·직장).
3. **신선도 갈래 재사용은 코드 실측대로만**: `get_data_freshness()` 의 `rule_kind` 는 `sangkwon`(YYYYMM 만) · `rone`(YYYYQn) · `seoul_openclose`(YYYYQ) · `permit`·`tx`(YYYYMM) · `nts`·`daejeon_closure`(YYYY-MM-DD) · `land_year`(YYYY). 추정매출·길단위인구 = `seoul_openclose` 재사용(+5개월−1일) · 가게 이력 = `sangkwon`(기준 = 결과표 last_ym YYYYMM) · 상주·직장 = ~~새 갈래 `seoul_yearly`~~ **`none`(예정일 없음 · 👤 10-31) + 기준 글 합성 · 새 갈래 0**(2026-10-31 PR② · 줄 셋 = 13 추정매출 · 14 길단위인구 · 15 상주·직장 한 줄) · SGIS = 새 갈래 `sgis`(받은 날 + 12개월) · 지하철 = 새 갈래 `subway`((기준월 + 2개월)의 5일 — 202609 → 2026-11-05). 신선도 함수를 다시 만드는 PR 마다: 갈래 추가 · comment 갈래 수 · `check_data_freshness.py` `SOURCE_HINTS` · 화면 `CARD_SOURCES` · 머리·comment 글자 대조 시험 · 날짜 단언 둘(예정일 null 아님 + 적재 당일 안 지남 · 양성 대조 짝) · post_load 공개 호출 허용 총계.
3-1. **(2026-10-31 PR② 덧붙임)** 13·14 줄 예정일은 `seoul_openclose` 규칙 그대로 20262 → **2026-10-31**(플랜·지시서의 「11-30」은 착오). 13·14 줄은 개업·폐업 11번 줄과 같은 자료·같은 분기라 같은 날 「지났습니다」가 뜨고 20263 을 함께 받으면 같이 풀린다(그물 6호 이슈가 자료마다 하나씩) — 수집 `--end-quarter` 는 게시된 최신 분기로(20263 → 2027-01-31).
4. **(2026-10-31 PR② 보완 F3 — 아래 원문보다 이 줄이 이긴다)** 수집 4종 끝 → `load_seoul_trdar.py --dry-run`(관문 통과 확인 · 관문 ⒤ 업종 코드는 실적재 트랜잭션 안에서 본다) → **같은 날** 마이그 적용 → 실적재 → post_load · `--check`. 마이그를 먼저 넣고 dry-run 이 걸리면 13·14·15 줄이 「자료 없음」으로 라이브에 남는다. 원문: **운영 순서(서울 4종)**: 디스크 판정 → **4종 수집을 다 끝낸 날** → 같은 날 마이그 적용 → **4종 한 트랜잭션으로 한 번에 적재**(일부 분기·일부 자료만 넣으면 신선도가 「지났습니다」 · 0033 때와 같은 교훈) → `post_load.py` · `--check` → 디스크 전후 PROGRESS. `collect_progress` 는 있는 표라 마이그 전에 수집할 수 있다.
5. **가게 이력 열쇠 규칙**(동시에 같은 간판 둘을 한 줄로 합치지 않게): ① 번호로 잇는다 ② 번호가 **끝난 사슬**(그 분기에 번호가 사라짐)에 한해, 다음 분기 새 번호 중 같은 (pnu, floor_no, 정규화 상호)가 **정확히 하나**일 때만 잇는다 ③ floor_no 가 둘 다 null 이면 잇지 않는다 ④ 상호 정규화 = 공백 제거 + 전각→반각(괄호 안 제거는 안 함) ⑤ 사슬의 값(상호·층)은 **마지막 분기 값** ⑥ 한 분기라도 빠지면 잇지 않는다(「빠졌다 복귀」는 새 사슬). 조사 C 의 「번호+땅·층·상호 · 중앙값 21 · 8분기 이상 67.9%」를 같은 규칙으로 재현해 ±2 안이면 통과.
6. **「2배」 식**: 범위(상한 − 하한) > 2 × 값 이면 범위만(값을 숨긴다) — 하한 = 통째로 든 집계구 합 · 상한 = 조금이라도 겹친 집계구 전부 합.
