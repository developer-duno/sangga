# 결정 0009 — 대전 상권 경계는 소진공 "주요상권현황"을 쓴다

> 결정일: 2026-08-14 · 결정: 사장님
> 관련: `0008`(서울 상권 소스 — "대전은 나중에 따로 정한다"의 그 '나중') · `0006`(서비스범위 서울+대전) · `0007`(보여주기는 상권 단위)
> 구현: 이 문서와 같은 PR (fetch/load 스크립트 + `district.source_nm` 칸 + 함수 `sources`)

## 한 줄

결정 0008 이 미뤄 둔 대전 상권 경계를 **소상공인시장진흥공단 "주요상권현황"**(data.go.kr
15090955)으로 채운다 — **대전 37개**(5개 구 전부), 이용허락 제한없음(상업 이용 가능).
같은 파일의 서울 176개는 **넣지 않는다**(서울 정본은 결정 0008 의 1,650개).

## 3. 채택 소스 실측 (2026-08-14, 파일 직접 다운로드)

- CSV 1개 **30.5MB cp949**, 전국 **1,227행**(포털 메타 "1,168"은 실제와 다름 — 실측 우선).
- 헤더: `상권번호,상권명,유형구분,시도코드,시도명,시군구코드,시군구명,상권좌표수,상권좌표,데이터기준일자`.
- 대전 37개 = 동구(대전역·중앙로역·가오·송촌…) 서구(둔산·탄방·용문역·도마·가수원…)
  유성구(유성온천역·노은역·반석역·구즉…) 중구(대전고속터미널·태평·문창·버드내…)
  대덕구(신탄진역·중리전통시장…) — **5개 구 전부**.
- 유형구분은 전 행 "주요상권"(⚠️ **꼬리 공백** — strip 필수). 서울 4종과 다른 5번째 유형.
- 좌표는 `경도,위도|…` 텍스트(WGS84) — 적재기가 한국 상자(경도 124~132·위도 33~39)
  관문으로 전 점을 검사한다(좌표계 관문 구멍 사고의 재발 방지, 0008/PR #50 결).
- ⚠️ **한 칸에 링이 여러 개다** — `)|(` 구분자로 **1,227행 중 440행(36%)**, 대전 37개 중
  **11개**가 다중 링(구멍 또는 별도 조각). 포털 미리보기(앞 50행)는 전부 단일 링이라
  이것만 보고 "링 하나"로 가정하면 틀린다 — **적대검증이 실제 파일 전수 실행으로 잡았다**
  (첫 구현이 실제로 그 가정으로 죽었다). 링 2,043개는 전부 이미 닫혀 있고,
  `상권좌표수` = 전 링 점 합계가 1,227행 전부 정확히 일치(실측).
- 겉/구멍 판정은 **우리가 하지 않는다** — 소스가 안 알려주므로 링들을 MULTILINESTRING
  으로 넘기고 PostGIS `st_buildarea`(even-odd 규칙)가 판정한다. 안쪽 링=구멍,
  떨어진 링=별도 조각. 면이 안 만들어지면 NULL 로 조용히 들어가는 것을 막는
  개수 점검이 적재 SQL 에 들어 있다.
- **R-ONE 임대통계 대전 상권명 12개 중 9개+ 가 이름으로 짝지어진다**(둔산·유성온천역·
  노은·목원대·가수원·용문·복합터미널·원도심·관평/구즉) — 임대 지표 조인의 앵커.
- 갱신: **비정기**(등록 2021-09, 수정 2025-08, 기준일 2024-01-01). 서울과 같은 처지라
  분기 크론으로 못 잡는다 — 갱신 감시는 0008 §8 의 미결 항목과 한 묶음.

## 4. 내려받기 경로 (포털 UI 없이 — 실측으로 확정한 2단계)

1. `https://www.data.go.kr/data/15090955/fileData.do` HTML 에서 `uddi:` 식별자 추출.
2. `/tcs/dss/selectFileDataDownload.do?publicDataPk=15090955&publicDataDetailPk=<uddi>` 는
   **파일이 아니라 JSON 메타를 준다**(함정) — 그 JSON 의 `atchFileId`·`fileDetailSn` 으로
3. `/cmm/cmm/fileDownload.do?atchFileId=<...>&fileDetailSn=<...>` 이 진짜 CSV. 로그인 불필요.

파싱 함정: 좌표 칸이 13만 자를 넘어 `csv.field_size_limit` 상향 필수.

## 5. 적재 설계에서 정한 것

| 항목 | 결정 | 왜 |
|---|---|---|
| `district_id` | `sbiz-<상권번호>` 접두어 | 서울 원본 코드(7자리)와 소진공(5자리)이 지금은 안 겹치지만, 맨 숫자끼리는 미래 충돌을 배제 못 한다 |
| 유령 감지 | **자기 소스(`sbiz-%`) 안에서만** | 서울 로더의 전역 감지를 그대로 쓰면 대전 적재 때 서울 1,650이 전부 "유령"으로 오탐 |
| 면적·중심 | SQL 에서 계산(`st_area(geography)`·`st_centroid`) | CSV 에 해당 칼럼이 없다 |
| 출처 문구 | `source_nm = '소상공인시장진흥공단'` | 화면이 이 문구를 그대로 보여준다(서울 행은 '서울특별시 상권분석서비스'로 백필) |
