# 알려진 한계 (기준선)

> **이 문서의 목적**: 매 세션 같은 것을 다시 발견하고 다시 조사하는 낭비를 막는다.
> 여기 있는 것은 **"이미 아는 것"** 이다. 새 세션은 이 목록을 먼저 읽고, 여기 없는 것만 조사한다.
>
> 담는 것 = **사실이지만 지금 구조상 어쩔 수 없거나, 나중에 손봐야 하는 것.**
> 담지 않는 것 = 고칠 수 있는 결함(그건 `PROGRESS.md`의 "다음 단계"로 간다).
>
> 최초 작성 2026-08-08 (3차 적대검증 legacy-limits 관점, 23개 항목 전수 사실 확인).
> **새 한계를 발견하면 여기 추가하고, 해소되면 취소선 처리 후 해소 근거를 남긴다.**

## 이 문서를 쓰는 법

- **조사 전에 먼저 읽는다.** 여기 있으면 다시 조사하지 않는다.
