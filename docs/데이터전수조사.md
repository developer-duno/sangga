# 상가 층별·업종별 공간분석 플랫폼 — 데이터 소스 전수조사

> 조사일: 2026년 8월 6일
> 목적: 상가를 층별·업종별로 공간분석하고 매매/임대 참고시세를 비교하는 플랫폼 구축을 위한 데이터 인벤토리

---

## 0. 3줄 요약

1. **층별·업종별 분석은 지금 당장 가능하다.** 건축물대장 「층별개요」와 소상공인 상권정보의 「층정보」가 둘 다 무료로 열려 있고, PNU코드로 연결된다.
2. **매매는 실측, 임대는 추정.** 상가 임대료 실거래 데이터는 국내에 존재하지 않는다. 밸류맵·디스코·부동산플래닛도 못 갖고 있다.
3. **차별화 지점은 "층 × 업종" 교차.** 기존 서비스는 전부 토지·건물 단위로 본다. 호실 단위로 내려간 서비스가 없다.

## 2. 데이터 연결 구조 — PNU가 열쇠

모든 데이터를 하나로 묶는 키는 **PNU코드(필지고유번호, 19자리)** 다.

```
PNU (19자리)
 ├─ 개별공시지가       → 필지 단가
 ├─ 토지특성정보       → 도로접면, 형상, 고저
 ├─ 건축물대장 표제부   → 건물 스펙
 ├─ 건축물대장 층별개요 → 층별 용도·면적   ┐
 ├─ 상권정보(층정보)    → 층별 업종·점포   ┤ ← 여기서 층으로 조인
 └─ 실거래가(층)       → 층별 거래가      ┘
```

**설계 원칙**: 테이블 3층 구조로 가세요.

| 레벨 | 키 | 담는 것 |
|---|---|---|
| 필지 | PNU | 공시지가, 용도지역, 도로접면 |
| 건물 | PNU + 동 | 연면적, 준공년도, 용적률 |
| **층/호** | PNU + 동 + 층 + 호 | **업종, 전용면적, 실거래가, 추정임대료** |

아파트는 2층 구조로 충분했지만 상가는 3층이 필요합니다.

## 3. 데이터 공백 지도 — 없는 것을 먼저 알아야 함

| 항목 | 상태 | 대응 |
|---|---|---|
| 상가 **임대료 실거래** | ❌ 존재하지 않음 | 신고 의무 없음. 세무서 확정일자 데이터는 이해관계인만 개별 열람 가능 (벌크 불가) |
| 개별 호실 **공실 여부** | ❌ 공식 데이터 없음 | **상권정보 분기 데이터 diff로 추정 가능** (아래 4-3 참조) |
| 상가 **실제 매출** | ❌ | 카드사 데이터는 유료·B2B |
| **유동인구** | △ | 서울은 열린데이터광장 무료. 전국은 통신사 유료 |
| 통건물 **정확한 지번** | △ | 실거래가에서 일부만 공개 |
| **권리금** | ❌ | 어떤 공적 데이터도 없음 |

> 참고: 업계 1위 서비스인 부동산플래닛도 "상업용 부동산은 전세 실거래가 정보가 제공되지 않는다"고 명시하고 있다. 이 공백은 개인의 역량 문제가 아니라 **제도의 문제**다.

## 4. 핵심 구현 설계

### 4-1. 층별 시세 추정 공식

```
층별 추정 매매단가 = 인근 동일층 실거래 ㎡단가 중앙값
                    × 도로접면 보정계수
                    × 준공년도 보정계수

층별 추정 월임대료 = (추정 매매가 × 지역 수익률 ÷ 12)
                    × 층별효용비율
```

- 인근 = 반경 300~500m, 최근 24개월
- 지역 수익률·층별효용비율 = 부동산원 D1
- 표본 3건 미만이면 → 시군구 평균으로 폴백 + "표본 부족" 표시

### 4-2. 업종 적합도 스코어

```
이 자리(층/호)에 A업종이 적합한가?

= 반경 500m 내 A업종 밀도 (경쟁)
× 반경 500m 내 A업종 보완업종 수 (시너지)
× 배후 세대수 / 직장인구
× 접근성 (도로접면, 역세권)
÷ 추정 임대료
```

층별로 적합 업종이 달라진다는 게 포인트입니다. 1층은 판매·음식, 2~3층은 학원·병원·미용, 지하는 주점·창고.

### 4-3. ★ 남들이 안 하는 것: 공실 추정

**소상공인 상권정보를 분기마다 받아서 diff를 뜨세요.**

```
2026 Q1: [PNU-A, 3층, 302호] = "○○학원"
2026 Q2: [PNU-A, 3층, 302호] = 없음
→ 폐업 또는 이전 → 공실 후보
```

이걸 누적하면 **호실 단위 공실 이력**이 만들어집니다. 국내 어떤 서비스도 제공하지 않는 데이터이고, 공개 데이터만으로 합법적으로 만들 수 있습니다. 3~4분기만 쌓여도 상권 쇠퇴/성장 신호가 보입니다.

**지금 당장 시작하세요.** 데이터는 과거로 소급이 안 됩니다. 이번 분기 스냅샷을 안 받으면 영원히 없는 데이터가 됩니다.

## 5. 경쟁 서비스 지형

| 서비스 | 강점 | 커버 단위 | 빈틈 |
|---|---|---|---|
| **밸류맵** | 2006년~ 실거래 축적, 토지·건물 가치분석, 건축설계·사업성검토 | 토지 / 건물 | 층별 분석 없음 |
| **디스코** | 실거래 3천만건, 등기 확인 실거래, 프랜차이즈 매칭 | 토지 / 건물 / 상가 | 업종×층 교차 없음 |
| **부동산플래닛** | 유형별 평균단가 지도 시각화, 노후도, AI대지권비율 | 유형별 / 지역별 | 개별 호실 단위 없음 |
| **아실** | 아파트 특화, 시계열 비교 UI 우수 | 아파트 | 상업용 미커버 |
| **네모·알스퀘어** | 사무실·상가 매물 중개 | 매물 | 시세 분석 약함 |

**결론: 빈 자리는 "호실 단위 × 업종 × 시계열"입니다.**
큰 회사들이 여기를 안 하는 이유는 못해서가 아니라, 데이터 정제 노가다 대비 수익 모델이 애매해서입니다. 반대로 말하면 중개업을 실제로 하는 사람이 만들면 이길 수 있는 영역입니다.
