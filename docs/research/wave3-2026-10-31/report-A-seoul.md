- **분기 인자 함정**: 추정매출·길단위인구·상권변화지표는 분기 인자가 먹습니다. 직장·상주·집객·아파트·소비는 인자를 무시하고 전체를 돌려주며 분기가 섞여 나옵니다. `collect_seoul_openclose.py`의 분기 한 칸씩 이어받기가 그대로 안 맞아, 쪽 번호 이어받기가 필요합니다.
- **중복 저장**: 연 1회 갱신 자료(직장·상주·집객·아파트)는 22분기를 다 넣으면 같은 값이 4번씩 들어갑니다.
- **갱신 표기와 API 차이**: 길단위인구는 「월간」, 상권변화지표는 「년간」이라 적혔지만 API는 분기 코드입니다. 백서 150행의 OA-15577 현상과 같습니다.
