## 0. 메인 추가 지시 — KOSIS 기업생멸행정통계 (결론)

| 항목 | 확인 결과 |
|---|---|
| 이름 | 기업생멸행정통계(국가데이터처 — 2026년 조직개편으로 통계청이 이 이름으로 바뀜, 원천=국세청 등 행정자료 가공) |
| 공간 단위 | **전국·시도 단위 보도자료만 공식 확인됨.** 시군구 단위 표가 KOSIS 포털에 있다는 1차 출처 확인에는 실패(로그인 리다이렉트로 표 자체를 못 열었음 — "확인 못 함"). 민원 게시판·보도자료 어디에도 "시군구" 세분화 수치를 직접 보여주는 페이지를 찾지 못했다. **행정동·상권 단위 표는 존재 자체를 확인하지 못함(없다고 단정하지 않음 — 확인 못 함).**
| 업종 분류 | 산업 대분류~중분류 수준으로 보이나(보도자료 기준), 세분류 단위의 공식 표 존재는 확인 못 함 |
| 대전 | 시군구 단위 자체를 못 열어서 대전 개별 수치 확인 못 함 |
| 최신 연도 | **2024년(잠정) — 2026년 발표분이 최신**(활동기업 764만2천개, 전년대비 +1.4%) |
| 이용허락 | KOSIS 공유서비스(OpenAPI)는 통계 전반에 일반 공개 — 이 표 개별 라이선스 문구는 확인 못 함 |
| MDIS 마이크로데이터 | **조건 한 줄: 통계청(국가데이터처) MDIS 사이트에 로그인 후 "이용센터서비스 신청"(연구계획서 포함 신청서 작성) → 담당자 심사·승인이 있어야 열람 가능 — 즉시 다운로드 불가.** 추가로 검색 결과 중 하나는 "기업생멸행정통계는 국세청 과세자료 기반 가공통계로 개인정보 보호 때문에 마이크로데이터 자체가 제공되지 않는다"는 설명도 나왔다(두 설명이 상충 — 확인 못 함, 둘 다 보고). |
| SGIS 기업생태분석지도 (참고) | **data.go.kr 에 "국가데이터처_SGIS_분석지도_…" 로 등재된 항목들을 열어 보니 전부 PDF 보고서/매뉴얼이고 수치 원자료가 아니다.** 실측 설명에 "지도 화면에서 경계·통계를 설정한 뒤 우측 상단 보고서 아이콘으로 **PDF 로만** 내려받는다"고 명시 — 메인이 말한 "내려받기 버튼이 없다"와 일치(정확히는 PDF 리포트 생성 버튼만 있고 CSV/수치 다운로드가 없음). 상권·전통시장 경계 집계 자체는 "경계업종집계"(창업생존율·평균존속기간 포함) 항목명이 검색에 걸렸으나 상세 페이지는 열지 못해 필드 전체는 확인 못 함. |

**결론**: 기업생멸행정통계는 시군구 이하 단위 수치를 공식 1차 출처에서 직접 확인하지 못했다. SGIS 기업생태분석지도는 상권·전통시장 단위로 보여주긴 하나 산출물이 PDF 리포트뿐이라 "받아서 가공"하기 어렵다(사람이 화면에서 설정 → PDF만 저장, API/CSV 없음). 가공 난이도 **상** — 추천 Top5에는 포함하지 않음.

## 2. 확인 못 함 (추가 확인 필요)

- **대전 전용 "온통대전" 가맹점 공공데이터셋**: 검색에서 타 지자체(청주·전주·춘천·인천 등)만 확인됐고 대전 항목을 못 찾음.
- **도로명주소 내비게이션용 DB(건물 출입구 좌표)**: 공식 설명은 확인했으나 **신청·심사 후에만 제공**(도로명주소법 시행령 46조 — 별도 신청서+이용목적 심사). 즉시 다운로드 불가능한 자료임이 확인됨(후보에서 "하" 난이도로 넣지 않음).
- **대전 지하철/도시철도 역별 승하차**: 대전은 도시철도 1호선만 있고, 공식 열린데이터 페이지에서 대전교통공사 직접 제공 데이터셋 URL을 못 찾음(버스 교통카드 연계데이터만 신호 확인).
- **한전 전력데이터 개방포털의 건물/PNU 단위 전력사용량**: "공공기관 그린버튼"은 공공기관 자체 건물 583곳 한정으로 보이고, 민간 상가 건물 단위 데이터 존재 여부는 확인 못 함.
- **KOSIS 기업생멸행정통계의 시군구·행정동 단위 공개 여부**: 위 0절대로 확인 못 함(로그인 리다이렉트로 실제 표를 못 열었음).
- **공정위 가맹사업 정보공개서의 지역별(시군구) 세분화 여부**: "지역기본정보" 필드가 있다고 나왔으나 그게 시군구 수준인지 시도 수준인지 상세 페이지를 못 열어 확인 못 함.

## 3. 추천 Top 5 (가공 난이도·화면 적합성·새로움 기준)

1. **지방행정인허가데이터(LOCALDATA)** — 이미 받는 일반음식점 표준데이터보다 **좌표·면적·폐업일자까지 포함한 더 풍부한 버전**이라, 지금 "서울 개업·폐업"에 쓰는 것과 같은 패턴을 195개 업종 전체로 확장할 수 있다. 결정 0033의 서울 전용 한계를 깨고 **대전 개폐업의 공식 길**이 될 가능성이 가장 크다.
2. **행안부 법정동별 주민등록 인구·세대현황(월간 OpenAPI)** — 생활인구(OA-23016)보다 가볍고 전국·월간이라 서울·대전 공통으로 배후 인구 추이를 바로 볼 수 있다.
3. **국민연금 가입 사업장 내역** — 상권정보에 없는 "그 구역에 직장인이 늘고 있나"를 공식 월별 시계열로 보여주는 유일한 자료.
4. **공동주택관리정보시스템(K-apt) 단지 정보** — 배후 아파트 세대수는 창업 상권분석의 기본 변수인데 지금 13종에 없다. 구조화가 깔끔해 가공 난이도가 낮다.
5. **행안부 대규모점포 등록현황** — 대형 집객시설(백화점·쇼핑몰) 위치는 상권 경쟁·보완관계 분석에 바로 쓸 수 있고 좌표까지 포함돼 난이도가 낮다.
