- **지도 좌측 메뉴**: 일반지도/위성지도/지형지도/테마/저장/지적편집도/거리뷰/반경측정/면적측정/거리측정/다운로드/인쇄 + **"부동산"**(네이버페이 부동산 연동 — 묶음A 1번에서 별도 조사 대상) · "거리/동/읍면/시군구/시도" 행정구역 레이어 전환 버튼 존재.
- **자료 종류**: 업체 위치·리뷰·영업시간·"방문자 리뷰"(사진·평점), 행정구역 경계 레이어 전환. 상권 통계(업종분포·유동인구·매출)는 안 보임.
- **역할별 질문**: 창업자("영업 중"으로 경쟁 가게 실시간 확인) = △ · 투자자·중개사 = X(부동산 탭은 네이버부동산으로 이동 — 별도 사이트, 묶음A 소관).
- **우리와 비교**: 겹치는 것 = 건물의 입점 업체 그룹핑 표시(목적은 다름, sangga 의 호실 구성표와는 수준이 다름) · 그쪽에만 있음 = 실시간 "영업 중" 상태, 방문자 리뷰·사진, 행정구역 레이어 전환 UI · 우리에만 있음 = 공식 통계 기반 상권분석 전부.
