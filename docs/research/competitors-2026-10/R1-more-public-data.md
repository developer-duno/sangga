# R1 — 더 받을 수 있는 무료 공공 자료 전수 조사 (2026-10-08)

> 진행 N/M: 완료(훑은 곳 약 20여 개 — 공공데이터포털·서울 열린데이터광장·브이월드·통계청 SGIS·국세청·한국부동산원·한국교통안전공단)
> 전제: `D:/sangga/docs/데이터백서.md` §4(173~186줄)에 이미 8개 후보가 상세 조사돼 있다 — 여기선 그걸 다시 적지 않고 "이미 후보"로만 표시, **새로 확인한 것** 위주.

## 1. 결론

1. **완전히 새로운 자료는 적다** — 사장님이 찾은 서울 상권분석서비스(10종×5단위)와 그 "같은 집안 형제"는 이미 백서 §4에 거의 다 올라가 있었다(길단위인구·상주인구·직장인구·소득소비·집객시설·아파트 전부 확인됨, 공공누리 1유형·반기~월간 갱신).
2. **새로 확인한 것 = 2건**: ① 국세청 "사업자등록정보 진위확인 및 상태조회 서비스"(건별 조회 API, 전국 — 단 **사업자등록번호를 미리 알아야 조회되는 구조**라 "동네 전체 개폐업 현황"을 못 만든다, 전수조회 불가) ② 한국교통안전공단 "교통카드 빅데이터"(전국 — 유동인구 대리지표 후보, 단 자료 범위·갱신이 지역마다 다르고 분석이 필요해 난이도 높음).
3. **대전 개업·폐업의 공식 길은 여전히 불확실** — 행안부 지방행정인허가(localdata.go.kr 폐쇄 → 공공데이터포털로 이관, 318개 데이터셋: 파일 178·API 31·연계 109)는 백서에 "후보"로 이미 적혀 있고, 이번 조사도 그 이상 확정하지 못했다(각 지자체별로 조각나 있어 "대전시 전체 일반음식점 인허가" 하나로 묶인 전국 표준 API를 이번에 특정하지 못함 — 더 깊은 조사 필요).
4. **식품위생업소 현황**(식약처)은 위생등급·안심업소 지정 데이터 2건만 확인됐고, 둘 다 "위생 평가" 성격이라 전체 개업·폐업 현황표가 아니다(확인 못 함 — 식품안전나라 API 포털 자체가 404로 직접 못 열어봄).
5. 법원 등기소(iros.go.kr)는 페이지가 비어 있어 확인 불가 — 등기 통계 공개 여부는 "확인 못 함".

## 3. 확인 못 함 (열리지 않음)
- localdata.go.kr, data.daejeon.go.kr, sgis.mods.go.kr(개별 페이지), vworld 개발자센터 API 목록, foodsafetykorea.go.kr API 포털, iros.go.kr(등기소) — 전부 404/DNS 실패. "없다"가 아니라 "이 세션에서 못 열었다."
- 식품안전나라 전체 API 카탈로그(음식점 폐업일자 필드 유무 미확인)
- 교통카드 빅데이터 개별 데이터셋(246개 파일 중 상가 분석에 쓸 만한 것 특정 못 함)

## 4. 추천 순서 Top 10

1. **서울 열린데이터광장 상권분석 형제군 전체 적재**(백서 §4 1순위 그대로) — 이미 조사 끝남, 공공누리 1유형 확인됨, 돈 0.
2. **생활인구 OA-23016**(백서 §4 기록) — 서울만이지만 즉시 적재 가능.
3. **소상공인365 상권분석 API**(백서 §4, 상업이용 가능 재확인됨) — 대전 포함 전국.
4. **SGIS 업종통계지도**(백서 §4) — 행정동 단위, PNU 변환 필요하나 전국.
5. **행안부 지방행정인허가**(이번 조사로 "318개 데이터셋 존재"만 재확인, 대전 개폐업 공식 길 여부는 다음 세션에 지자체별 데이터셋 하나하나 열어봐야 확정) — 서울 외 지역 개폐업의 유일한 희망.
6. **국세청 사업자등록 상태조회 API** — 전수조회는 안 되지만, 이미 우리가 가진 점포 목록(상권정보)의 **개별 업체 생존 여부를 보강 검증**하는 용도로는 쓸 수 있음(돈 0, 일 100만건).
7. **LH·청약홈 분양 공고**(백서에 이미 기록) — 신규 아님, 재확인만.
8. **부동산원 상가권리금 통계**(백서 §3에 이미 반영) — 시·도 단위 참고 배경으로만.
9. 교통카드 빅데이터 — 난이도 높아 후순위, 유동인구 대리지표 가치는 있으나 전국 통합이 안 돼 있어 조사 공수 큼.
10. 식약처 위생등급·안심업소 — 상가 분석과 직접 관련 낮음, 우선순위 최하위.

**새로 찾은 것 = 2건**(국세청 사업자상태조회, 교통카드 빅데이터) · **그중 바로 받을 만한 것 = 1건**(국세청, 단 보강용) · **대전 개폐업 공식 길 = 아직 미확정**(행안부 인허가가 유력 후보이나 이번 조사로 확정 못함, 다음 세션에서 지자체별 데이터셋을 직접 열어 "대전광역시" 필터로 좁혀야 함).
